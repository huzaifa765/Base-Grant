# BaseGrants

A decentralized grants protocol built on Base.

## Overview
Community members deposit ETH into a shared pool, 
submit grant proposals, and vote on funding decisions. 
Proposals passing 60% quorum are automatically funded.

## Features
- ETH pool with minimum 0.001 ETH deposit
- On-chain proposal submission
- 3-day voting period
- 60% quorum for approval
- Automatic ETH transfer on passing
